# Поездки с Олегом

Учёт поездок и оплат: календарь дней, долг Олега, оплата за выбранные дни. Работает без сервера, данные хранятся в браузере телефона.

## Как выложить на GitHub Pages

1. На github.com нажмите **New repository**, назовите, например, `oleg-trips`, создайте.
2. Нажмите **uploading an existing file** и перетащите в окно **все файлы из этой папки** (сами файлы, а не папку), затем **Commit changes**.
3. Откройте **Settings → Pages**. В «Branch» выберите `main` и `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/oleg-trips/`.

## Установка на iPhone

Откройте адрес в Safari, нажмите «Поделиться» → «На экран Домой». Приложение откроется без адресной строки и будет работать без интернета.

## Важно

- Данные лежат только на устройстве. Чтобы перенести их на другое, в самом низу приложения есть «Скачать копию» и «Загрузить копию».
- Начальные данные (ваша таблица) зашиты в `index.html`. Если репозиторий публичный, их увидят все, у кого есть ссылка. Уберите их в `index.html` (переменная `SEED`) или сделайте репозиторий приватным.
- Версия на GitHub не синхронизируется с версией в Claude: у каждой свои данные.
